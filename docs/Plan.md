# Idea : Develop an app that lets customers see the water usage of not only their food, but also things like products, drives, and things to measure their daily water footprint 
## Goal : provide customers a stable "tracker" for water footprints, much like a calorie tracker app. Make it as seamless as possible 


## End product 
(1)An app that can function with extreme smoothness and polish on a phone/tablet
(2)The user takes a photo of the product they are using --> can track water
(3)Powered by a LLm agent with a reliable database
